The workflow

Follow a finding.

  1. Bring the report

    Pull report metadata from HackerOne or Bugcrowd. A private inventory maps it to a service, component and deployed revision.

  2. Read the evidence

    Compare a staging manifest with approved settings. Each observation retains its check result, run ID and revision in HydraDB.

  3. Hand off the review

    A reviewer confirms the owner. A coding agent can claim a scoped assignment through MCP and record its decision for the next review.
